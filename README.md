# Prism

面向短视频的原生 iOS 本地播放器。首页直接检索文件；播放器提供实时拖动定位、前后逐帧、捏合放大和上下滑切换。

当前版本 **0.3.2（Build 16）**。这一版换上新的玻璃棱镜图标，在媒体库首页左上角加入同款标志，并修复图片很多时滑动卡住的问题。完整清单见下方“0.3.2 更新”。使用和安装步骤见 [开始使用.md](开始使用.md)。

## 0.3.2 更新

图标与标志

- App 图标换成 B 方案：深色背景上的玻璃三角棱镜，同时也是播放键，光在棱镜内折射成光谱。源文件为 `Design/AppIcon-B.svg`，旧的 C 方案源文件已移除。
- 媒体库首页（根目录）左上角显示同款棱镜标志，点按打开“关于 Prism”。进入文件夹后，左上角仍是返回按钮。标志为 1x/2x/3x 位图（`PrismMark`），按原色显示，不跟随强调色着色；在 iOS 26 上不加 Liquid Glass 底板。

图片很多时的流畅度

- 后台补读尺寸和时长的结果改为分批写入：每批一次列表更新、一次索引写入。原来每读完一个文件就刷新一次整个媒体库并重写一次索引文件，导入几百张图片后，网格要跟着反复重绘很长一段时间，滑动随之卡住。
- 连续触发的刷新会合并：Wi-Fi 传输每完成一个文件就刷新一次，现在正在扫描时再来的请求只会在扫描结束后合并成一次补扫，并丢弃过时的扫描结果。
- 缩略图解码限流：同时最多解码 3 个原图、读取 2 个磁盘缓存，优先处理最新出现的格子；已经滑出屏幕的格子会撤销尚未开始的解码。原来快速滑动时每个经过的格子都会启动一个不可取消的解码，屏幕上的格子要排在它们后面。
- 网格缩略图不再在每个格子里使用 `GeometryReader`；读取原图时不再让图片源缓存整张解码结果（`kCGImageSourceShouldCache: false`），降低解码时的内存峰值。
- 全屏看图从 SwiftUI 分页 `TabView` 改为 `UIPageViewController`：任何时候只存在当前页和相邻页，翻页开销与图片总数无关。翻页时先显示网格里已有的缩略图，再换成清晰原图。大图有独立的内存缓存（约 6 张），来回翻页不必重新解码，也不会把网格缩略图挤出缓存。
- 看图页不再订阅整个媒体库的变化；VoiceOver 三指左右轻扫可以翻页并朗读“第几张，共几张”。

## 0.3.1 更新

播放体验

- 断点续播：15 秒以上的视频记住停下的位置，再次打开从那里继续，顶部提示可选“从头播放”；看到结尾或停在开头几秒时不记录。媒体库缩略图底部显示观看进度。
- 轻点画面立即显示或隐藏控件：去掉双击放大（它让每次单击都要等约 0.3 秒），改为双指捏合放大，最多 4 倍，放大手指所在位置；放大后单指拖动查看局部，“还原画面”或捏回恢复。
- 时间数字改用系统等宽数字，不再左右跳动；播放时只显示到秒，暂停、逐帧和拖动时显示毫秒。
- 上下滑动画面切换下一个／上一个视频；“更多 → 播完后”可选停在末尾、单条循环或播放下一个。
- 接入 `MPRemoteCommandCenter`：AirPods、线控和控制中心可播放、暂停、拖动进度，列表中可切换上一个／下一个。
- 播放页：主控居中，播放／暂停同一套图标；左下角倍速按钮就地选择 0.25×–2×；A–B 区间直接画在进度条上，选择“A–B 区间循环”后在进度条上方就地设 A、B 点；横屏按钮只给横向视频，收起用另一个图标；锁定后“解锁”只在轻点屏幕时出现；加载提示延迟 0.3 秒，本地文件不再闪一下；逐帧、设点、拖到头尾、切换视频有触感反馈。
- 播放页始终使用整个屏幕，控件隐藏时同时隐藏状态栏和主屏幕指示条；横屏模式在连续的横向视频之间保持，不再来回旋转。
- 字幕大小可选小／标准／大／特大；竖着看横向视频时字幕自动放大 1.5 倍。
- “更多”面板：文字统一白色，强调色只用在图标上；倍速移到播放页；“操作手势”移到最下面；面板标题与文档统一为“更多”。

性能

- 播放时间改由独立的 `PlaybackClock` 发布，只有时间、进度条和拖动浮层随帧刷新，控件隐藏时停止刷新；画面层不再每帧重建无障碍操作。
- 媒体库已知视频分辨率时，渲染目标不超过视频本身所需：1080p 视频在 iPhone 15 Pro 上从 3328² 降到 2048²，竖屏小窗时 GPU 像素量约为原来的 38%。
- 缩略图加入磁盘缓存（Caches/Thumbnails），冷启动不再重算；滚动回来的行不再闪占位图；视频封面取开头 10%（最多 1 秒）处，避开片头黑场。

媒体库与传文件

- 右上角“选择”改为文字按钮（原来是滑杆图标）；搜索改用系统搜索栏，可随滚动收起；数量与排序合并为一行并随列表滚动，排序改为菜单；去掉底部常驻说明。
- 强调色收敛：分段控件选中项、文件夹图标和空状态图标改为中性色。
- 进入文件夹后只显示该文件夹的内容，不会再被“所有视频”带回根目录。
- 图片改为 3 列以上的无字方格；图片查看器纯黑背景，轻点隐藏上下栏，去掉常驻手势提示。
- 传文件页：开启后地址作为页面上最大的字显示（省略 `http://`），重复说明合并为一行；优先使用固定端口 8080，被占用时自动换用其他端口。
- 新增“+ → 关于与开源许可”，App 内可查看版本、第三方组件说明、LGPL 与 D-DIN 许可文本。

手势说明可在播放器右上角“更多 → 操作手势”点开，也可阅读 [操作手势 README](docs/GESTURES.md)。

## 当前实现

- SwiftUI 媒体库：所有视频／所有图片／文件夹；按名称搜索，按名称、导入时间、时长、大小升降排序，记住排序偏好。
- 每页一个文件导入入口：媒体库右上角 `+` 菜单，传文件页“从文件导入”；空状态只显示指引。支持文件夹管理、批量移动与删除、重命名。
- 文件夹右侧“更多”、左滑和长按均可删除文件夹；进入目录后，右上角 `+` 菜单也可删除当前目录。确认后删除整个目录及其内容，成功后立即刷新；删除当前目录时返回上一级。
- 删除或移动文件成功后自动清理变空的源目录及上级；启动时清理遗留空目录。保留含图片、字幕、隐藏文件或其他内容的目录，以及媒体库根目录。
- 图片分页（只保留当前页与相邻页）、缩放、分享；缩略图限流解码与缓存，后台元数据分批读取。
- libmpv／FFmpeg 实际解码后端，覆盖常用容器；VideoToolbox 硬件解码优先。
- 拖动时直接更新主视频画面；只保留最新的等待定位请求。松手后执行精确定位，保持拖动前的播放／暂停状态。
- 从视频画面或黑边任意位置水平拖动，向右快进、向左快退；显示目标时间和前后移动秒数，拖动时实时更新主画面。按钮及时间轴保留原有操作，竖向拖动不会触发定位。
- 横拖允许轻微斜向起手；慢拖不再被一次性方向判定拒绝。按住后继续横移可从临时快放切换到定位；连续横拖无需等待上一目标解码完成，仍保留最初的播放／暂停意图。
- 前后逐帧使用实际解码帧定位，支持变帧率文件；不使用固定时间步长模拟。
- 15 秒以上的视频断点续播，媒体库缩略图显示观看进度。
- 逐帧图标采用单格胶片与左右细箭头，区别于上一首／下一首；长按按钮可连续逐帧。
- 长按视频画面 0.35 秒后临时以 2 倍速播放，松手恢复之前的倍速；原来暂停的片段会恢复暂停。锁定、后台、中断和退出会取消临时快放。
- 倍速（播放页左下角）、播完后（停在末尾／单条循环／播放下一个）、音轨、内置与 SRT／ASS／SSA／VTT 外挂字幕及字幕大小、锁定触控、横向视频横屏播放。
- 「更多 → 当前列表」沿进入播放器时的搜索／文件夹与排序结果手动切换视频。
- 「更多 → 保存当前帧」暂停在当前画面，生成原显示分辨率的 PNG，可存到文件、相册或分享。
- 「更多 → A–B 区间循环」使用当前画面设置两点，重复查看片段中的一小段。
- 从“文件”App 或提供打开方式的文件服务选择 Prism，直接播放该视频。需要留存时，在「更多」中选择“保存到媒体库”。
- 耳机或蓝牙音频输出断开时暂停。暂停后操作、逐帧或拖动结束后延长约 60 秒的防锁屏时间。
- 双指捏合放大到手指所在位置（最多 4 倍），放大后单指拖动查看局部，不改变播放／暂停状态；轻点立即切换控件，长按临时 2×，上下滑切换视频。
- 播放页面仅保留返回、文件名、更多、倍速、时间轴和必要播放按钮；正常播放 3 秒后自动隐藏，轻点画面显示或隐藏。播完后行为、A–B、字幕等收进“更多”。
- 播放页始终全屏；横向视频可切换到横屏，按实际显示尺寸和旋转信息判断，收起后恢复之前的屏幕方向。
- 同一 Wi-Fi 的浏览器批量上传；流式写入文件、进度、取消／重试、空间检查与失败清理。
- USB 文件共享，以及“文件”App 中的 Prism 文件夹。

当前环境可以运行纯 Foundation 的 Swift 测试，不能运行 Xcode、模拟器或 iPhone。实际构建及性能验收状态见 [VALIDATION.md](VALIDATION.md)。这份工程尚未生成签名 IPA。

## 在 Mac 上运行

先双击根目录的 `准备工程.command`，或在终端进入源码目录执行 `bash scripts/prepare-mac.sh`。工具会检查目录完整性和依赖连接，失败日志保存在 `.prism/logs/`。针对 GitHub SSL 错误的说明见 [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md)。

1. 使用 Xcode 16 或更新版本打开 `Prism.xcodeproj`，选择 `Prism` scheme。
2. 等待 Swift Package 下载完成。MPVKit 包含较大的解码库，首次解析需要联网。
3. 选择 iPhone 模拟器运行；连接真机时，在 Signing & Capabilities 中选择自己的开发团队，并按需修改 Bundle Identifier。
4. 启动后从右上角 `+` 导入视频，或者进入“传文件”开启 Wi-Fi 接收。电脑与手机连接相同 Wi-Fi，在电脑浏览器输入手机显示的完整地址，再拖入文件。

正常启动的媒体库为空，不展示虚构文件。需要演示／UI 测试素材时，在 Scheme → Run → Arguments 中添加 `-prism-sample-media`，会导入随工程提供的短测试片段和图片；不会重复导入已存在的同名素材。

## 核心交互

播放时拖动会先暂停声音，主画面随定位请求更新。跨度较大时允许先用关键帧预览，停住后细化到实际目标。松手定位到实际画面，再恢复拖动前的播放状态。暂停后拖动仍使用精确预览，可以接着逐帧微调。

长按画面快放与逐帧按钮的长按分开处理。快放期间显示“2× 倍速播放”，松手恢复原先的 0.5×／1×／1.5× 等设置；若快放到末尾，会停在末帧，松手不重新开始。横屏和竖屏均可轻点画面显示或隐藏控件。

控件在正常播放且无操作时 3 秒后隐藏，任何按钮操作后重新计时。暂停时控件自动显示且不自动隐藏，也可以轻点画面隐藏，以便检查单帧。拖动定位、设置弹层、倍速选择、A–B 设点、加载、错误及 VoiceOver 使用期间保留控件；长按 2× 不改变原本的菜单显隐，锁定后轻点屏幕显示解锁按钮。控件淡入淡出只改变叠加层，不改变视频区域尺寸。

“所有视频／所有图片”汇总 Prism 内已导入的文件，不请求或扫描整个系统相册。进入某个文件夹后，搜索覆盖该文件夹及其子文件夹；点击顶部分类可回到全局汇总。

删除或移走最后一个文件后，源目录如果已经没有任何内容，会自动删除；如果上级也变空，则继续向上清理，始终保留媒体库根目录。App 启动时也会清理旧版本遗留的空目录。新建目录不会在本次正常刷新时立即删除，仍可用作导入或移动的目标；若一直未使用，会在下次启动时清理。

自动清理按实际文件系统内容判断，不按“0 个视频”判断：图片、字幕、隐藏文件、其他文件和符号链接都算内容。使用系统原子空目录删除操作，过程中有新文件进入则保留目录。移动目的地会保留；文件操作或索引提交失败时不清理原目录。手动删除整个非空目录仍需确认，取消不改变内容。

媒体库的缩略图固定在 96×64 槽位内显示。视频优先使用系统解码读取封面及信息，兼容格式失败时使用单个后台解码器补齐缩略图、时长和尺寸。

横屏判断使用 mpv 的显示宽高、显示宽高比和剩余旋转角度，包含手机 MOV 常见的 90°／270° 旋转信息。视频画面保持比例完整显示；尺寸信息未就绪时不显示横屏按钮，避免按编码宽高误切方向。

播放与暂停共用同一个 Metal surface 和等比例布局。开始播放时按屏幕像素、内存、低电量模式、温度以及媒体库已知的视频分辨率选择渲染尺寸，之后固定到本次播放结束。高分辨率设备可保留更多细节，HDR 片源在 sRGB 输出上做色调映射。具体实现和真机验收范围见 [Playback README](Playit/Playback/README.md)。

Wi-Fi 传输请在电脑浏览器输入手机显示的 `IP:端口` 地址（优先使用 8080 端口，收藏后下次仍可使用）；根地址会跳转至当前会话，省略会话尾斜杠也可自动补全。启动时的短暂网络等待会保留监听，并显示状态说明。Wi-Fi 接收需要 App 保持前台。接收期间会防止自动锁屏；进入后台、关闭接收或 Wi-Fi 改变时会停止连接，电脑页面可以重新上传。已完成的文件会保留，未完成临时文件会清理。USB 拷贝后回到媒体库或下拉刷新即可看到文件。

## 工程结构

```text
Playit/App                 App 生命周期、标签、播放器入口与“关于”页
Playit/Design              命名配色、原始 Figma 图标、品牌标志、格式化、等宽数字与触感反馈
Playit/Library             文件库界面、后台数据与图片预览
Playit/Playback            libmpv 串行后端、持久 Metal surface 与系统播放控制
Playit/PlayerUI            播放界面、精确时间轴与逐帧按钮
Playit/Transfer            本地 HTTP 接收服务及电脑上传网页
Playit/TransferUI          手机传输页面和 USB 指引
Packages/PlayitCore        媒体模型、检索排序、文件仓库与测试
Packages/PlayitTransferCore HTTP 解析、文件策略与测试
PlayitUITests              iOS 检索、逐帧／拖动与 USB 指引测试
```

为兼容既有工程与数据，内部源目录和 Package 名称仍为 Playit／PlayitCore；桌面显示名为 Prism，Xcode 工程与 scheme 为 Prism。覆盖安装时请使用原 Team 和 Bundle Identifier，以保留已导入文件。

新增源文件后运行 `python3 scripts/generate-project.py` 刷新工程。它只生成项目配置，不修改业务代码。

## 设计与依赖

UI 根据已确认的 [Figma 设计稿](https://www.figma.com/design/BArF6b7dUx2MvAV8U5coxI?node-id=3-59) 及真机反馈实现，采用深色背景和 `#C4F582` 浅绿色强调色。所有交互强调色直接使用同一品牌资源，并同步到 SwiftUI、实际 UIWindow 和 UIKit 控件。

字体使用 [SpaceX 官网声明的 D-DIN 字体](https://www.spacex.com/styles.1a4bd8588c6ea618.css) 对应的开源 Regular／Bold 字体文件，覆盖 App 内文字和电脑上传页。英文与数字使用 D-DIN；该字体不包含中文，中文由 iOS 系统黑体回退显示。D-DIN 的数字宽度不一（“1”比“8”窄约 36%）且没有等宽数字特性，所以时间、计数、地址等会变化的数字改用系统等宽数字（`AppTypography.numeric`）。字体跟随 Dynamic Type，保持文字可读。字体来源与许可见 `THIRD-PARTY-NOTICES.md`。

图标从原始 Figma 图层导出为本地矢量资源，没有运行时临时素材 URL。

0.3.1 新增的暂停、横屏和收起图标按同一网格与线宽绘制，记录在 `Design/asset-manifest.json` 的 `additions` 中。
