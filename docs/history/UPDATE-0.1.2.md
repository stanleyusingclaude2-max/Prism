# 在 iPhone 上更新到 0.1.2

1. 解压新版源码，使用 Xcode 打开 `Playit.xcodeproj`。
2. 在 `TARGETS → Playit → Signing & Capabilities` 选择之前的 Team，Bundle Identifier 填成上次安装使用的相同值。
3. 连接并解锁 iPhone，在 Xcode 顶部选中这台手机，按 `⌘R` 编译覆盖安装。保持相同的 Team 和 Bundle Identifier，可保留已导入的媒体文件。

本轮版本号为 **0.1.2，Build 3**。请打开完整的新工程，其中包含新的布局逻辑、控件状态模型与项目引用。

本次改动：

- 极简播放菜单：正常播放无操作 3 秒后隐藏，轻点画面显示或隐藏；倍速、循环、音轨、字幕等放在右上角“更多”。
- 暂停与逐帧时不自动隐藏，仍可轻点手动隐藏；拖动定位期间控件保留。长按临时 2× 功能继续保留。
- 播放和暂停共用相同的等比例布局，修正全屏区域未正确适配和暂停帧拉伸的底层尺寸同步问题；横片、竖片和带旋转信息的 MOV 继续按真实方向自适应。

手机上重点复测：分别打开横片和竖片，全屏后反复暂停／播放，再在暂停时收起／进入全屏。画面应居中、完整显示，人物比例和画面尺寸不因暂停而变化。视频与屏幕比例不同会保留必要黑边。

源码检查及纯 Swift 测试结果见 `VALIDATION.md`。当前环境无法运行 Xcode 或 iPhone，因此 Metal 实际画面与全屏切换仍需在手机上确认。
