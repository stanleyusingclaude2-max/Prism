# 在 iPhone 上更新到 0.1.4

1. 解压新版源码，用 Xcode 打开 `Playit.xcodeproj`。
2. 在 `TARGETS → Playit → Signing & Capabilities` 保持之前的 Team 和 Bundle Identifier。
3. 连接并解锁 iPhone，在 Xcode 顶部选中手机，按 `⌘R` 覆盖安装。相同的 Team 和 Bundle Identifier 可保留已导入的媒体文件。

版本为 **0.1.4，Build 5**。空文件夹现已自动清理，无需再手动删除。

- 删除或移走最后一个文件后，自动删除变空的源目录；上级目录也变空时继续清理，保留媒体库根目录。
- 启动时清理以前遗留的空目录；当前浏览的目录被清理后，返回最近仍存在的父级。
- 含图片、字幕、隐藏文件或其他内容的目录保留。新建目录在当前使用过程中仍可用作导入目的地，未使用的空目录下次启动时清理。

重点复测：进入只含一个视频的文件夹并删除视频，应自动返回父级，文件夹随之消失；多层空目录一同清理，其他文件及移动目的地保留。

纯 Swift 测试及源码检查结果见 `VALIDATION.md`。当前环境无法运行 Xcode 或 iPhone，实际界面仍需手机复测。
