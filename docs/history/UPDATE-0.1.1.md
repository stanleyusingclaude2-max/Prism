# 在 iPhone 上更新到 0.1.1

1. 解压新版源码，使用 Xcode 打开其中的 `Playit.xcodeproj`。
2. 在 `TARGETS → Playit → Signing & Capabilities` 选择之前的 Team，并将 Bundle Identifier 填成上次安装时使用的相同值。
3. 选择已连接、解锁的 iPhone，按 `⌘R` 编译覆盖安装。使用相同的 Team 和 Bundle Identifier 可保留原 App 已导入的媒体文件。

本轮版本号为 0.1.1，Build 为 2。新工程已包含字体资源和方向管理代码；单独复制几个 Swift 文件不足以更新所有资源与项目设置。

重点复测：

- 竖视频缩略图与文件信息排列在同一行，加载图片后没有越界。
- `+`、底部标签、播放键与进度条使用相同浅绿色。
- 英文与数字使用 D-DIN；中文正常显示。
- 竖拍 MOV 全屏保持竖向，横片全屏才转横向；收起恢复原方向。
- 长按 2×、松手恢复、逐帧及拖动预览继续正常。

如果 Xcode 报错，提供第一条红色错误的完整内容。当前交付仍是源码工程；新的真机显示与方向切换需在手机上复测。
