# 在 iPhone 上更新到 0.1.3

1. 解压新版源码，用 Xcode 打开 `Playit.xcodeproj`。
2. 在 `TARGETS → Playit → Signing & Capabilities` 保持之前使用的 Team 和 Bundle Identifier。
3. 连接并解锁 iPhone，在 Xcode 顶部选中手机，按 `⌘R` 覆盖安装。保持相同的 Team 和 Bundle Identifier，可保留已导入的媒体文件。

本轮版本为 **0.1.3，Build 4**，修复文件夹无法删除的问题。

在媒体库的“文件夹”分类中，点击文件夹右侧“更多”→“删除文件夹”，确认即可。也支持左滑或长按；进入空目录后，可以从右上角 `+` 菜单删除当前文件夹。删除完成后更新列表，删除当前目录会返回上一级。

删除文件夹会连同其中的全部文件、子文件夹一起删除，操作前会确认。仅删除最后一个视频会保留空目录，需要时再手动删除目录。

重点复测：取消删除后目录还在；确认后立即消失；同名目录可以重新创建；删除当前目录能返回父级，不出现错误弹窗或旧目录重新出现。

测试结果见 `VALIDATION.md`。当前环境无法运行 Xcode 或 iPhone，界面操作仍需在手机上复测。
