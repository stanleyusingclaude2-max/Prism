# Prism 操作手势

在播放器右上角点“更多”→“操作手势”，可以随时打开 App 内指南。控件隐藏时，先轻点画面。

## 画面手势

| 操作 | 效果 |
| --- | --- |
| 左右拖动 | 在视频画面任意位置向右拖动快进，向左拖动快退，轻微斜向起手也可识别。画面实时预览；松手后恢复拖动前的播放或暂停状态。 |
| 上下滑动 | 向上滑切到下一个视频，向下滑回到上一个，顺序与进入播放器时的列表一致。到头时会提示；列表只有一个视频时不响应。 |
| 轻点画面 | 立即显示或隐藏播放控件。播放时无操作 3 秒后自动隐藏；暂停时不会自动隐藏，也可以轻点收起。 |
| 双指捏合 | 两指张开放大手指所在的位置，最多 4 倍；放大后单指拖动查看其他区域。捏回原大小或点顶部“还原画面”恢复完整画面。播放状态保持不变。 |
| 长按画面 | 按住约 0.35 秒，临时以 2 倍速播放。松手恢复原先倍速；原来暂停的视频会恢复暂停。按住后横向拖动，可切换为定位视频。 |

画面手势也适用于视频周围的黑边。请避开按钮，从画面中间开始拖动或滑动；屏幕边缘的手势由 iOS 处理。

## 精确控制

| 操作 | 效果 |
| --- | --- |
| 轻点上一帧／下一帧 | 胶片箭头按钮用于逐帧：暂停并查看上一帧或下一帧，每一帧有轻微触感。长按按钮可连续逐帧。 |
| 拖动时间轴 | 实时查看目标画面；松手后精确定位，并恢复拖动前的播放或暂停状态。拖到开头或结尾时有触感提示。播放时时间只显示到秒，暂停后显示到毫秒。 |
| 轻点左下角倍速 | 在播放页上直接选择 0.25×～2×；不是 1× 时按钮高亮。 |
| 轻点横屏按钮 | 只在横向视频上出现，转为横屏播放；再点一次恢复。连续播放横向视频时保持横屏。竖向视频竖着拿手机就是全屏。iPad 和展开的 iPhone Duo 等宽屏上不显示，横向视频直接以足够大的尺寸播放。 |
| 锁定触控 | 在“更多”中选择“锁定触控”，停用画面手势和播放控件。轻点屏幕会显示“解锁”按钮，3 秒后自动隐藏。 |

逐帧按钮不会切换到其他视频。拖动、逐帧和临时倍速是不同操作；查看细节时可先暂停，再拖动或逐帧。

## 「更多」中的操作

- **播完后**：停在末尾、单条循环或播放下一个。选择会被记住。
- **A–B 区间循环**：选择后，播放页底部出现 A、B 按钮。拖动或逐帧到起点点 A，再到终点点 B，播放器会从 A 开始循环这一段，进度条上标出区间。点“清除”恢复普通播放，点“完成”收起按钮。
- **当前列表**：按进入播放器时看到的顺序列出视频（带缩略图），可选择上一个、下一个或任意一条。
- **保存当前帧**：暂停在当前画面，生成原显示分辨率的 PNG，可存到相册、文件或分享。
- **字幕大小**：小、标准、大、特大。竖着看横向视频时字幕会自动放大。
- **保存到媒体库**：用于从“文件”打开的外部视频。需要长期保留时才选择保存。

## 断点续播

15 秒以上的视频会记住上次停下的位置，再次打开时从那里继续，顶部提示中可点“从头播放”。在开头几秒或结尾附近停下时不记录。媒体库缩略图底部的细线显示观看进度。

## 耳机和控制中心

AirPods、有线耳机线控和控制中心可以播放、暂停和拖动进度；列表中有多个视频时，可用“下一首／上一首”切换视频。
