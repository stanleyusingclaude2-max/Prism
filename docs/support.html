Prism 技术支持

Prism 是面向短视频的本地播放器：快速检索文件，实时拖动定位、逐帧查看、捏合放大，通过 Wi-Fi 从电脑传入文件。

常见问题

怎么把视频放进 Prism？

  • 从“文件”App 导入：媒体库右上角 + → 导入。
  • Wi-Fi 传输：打开“传文件”页并开启接收，电脑和手机连同一个 Wi-Fi，在电脑浏览器输入手机上显示的地址，拖入文件即可。传输期间请让 Prism 保持在前台。
  • USB：在 Mac 的访达（或 Windows 的 Apple 设备 / iTunes）文件共享中，把文件拷进 Prism，回到媒体库下拉刷新。
  • 直接打开：在“文件”App 中选择视频 → 分享 → Prism，可直接播放。

电脑打不开传输地址？

  1. 确认手机和电脑连的是同一个 Wi-Fi（部分公共 / 访客网络会隔离设备）。
  2. 在 iPhone“设置 → 隐私与安全性 → 本地网络”中允许 Prism。
  3. 地址要完整输入，包括冒号后的端口号，例如 192.168.1.8:8080。
  4. 关闭电脑或手机上的 VPN 后再试。

支持哪些格式？

Prism 使用 libmpv / FFmpeg 解码，支持 MP4、MOV、MKV、AVI、WebM 等常见格式，以及内置字幕；SRT、ASS、SSA、VTT 外挂字幕可在播放页“更多”中载入。

常用手势

  • 轻点画面：显示 / 隐藏控件。
  • 左右拖动画面：快进 / 快退定位。
  • 长按画面：临时 2 倍速，松手恢复。
  • 双指捏合：放大画面，最多 4 倍。
  • 上下滑动：切换上一个 / 下一个视频。

完整说明在播放页右上角“更多 → 操作手势”。

删除 App 会怎样？

导入到 Prism 的文件只保存在 App 内，删除 App 会一并删除。请先在“文件”App 中把需要的文件拷出。

开源组件源码

FAQ

How do I add videos?

  • Files app: tap + in the Library, then Import.
  • Wi-Fi Transfer: open Transfer and turn on receiving. With your phone and computer on the same Wi-Fi, enter the address shown on your phone in a computer browser and drop files in. Keep Prism in the foreground while transferring.
  • USB: use File Sharing in Finder (or Apple Devices / iTunes on Windows) to copy files into Prism, then pull to refresh.
  • Open in place: in the Files app, share a video to Prism to play it directly.

My computer can't reach the transfer address

  1. Make sure both devices are on the same Wi-Fi network (guest networks often isolate devices).
  2. Allow Prism in Settings → Privacy & Security → Local Network.
  3. Type the full address including the port, e.g. 192.168.1.8:8080.
  4. Turn off any VPN and try again.

Supported formats

Prism decodes with libmpv / FFmpeg and plays MP4, MOV, MKV, AVI, WebM and other common formats, with embedded subtitles. External SRT, ASS, SSA and VTT subtitles can be loaded from the More menu in the player.

What happens if I delete the app?

Files imported into Prism live inside the app and are deleted with it. Copy anything you want to keep out through the Files app first.
